# Frameworks e Bibliotecas do Frontend

**Descrição**: Este documento define a stack base permitida para projetos frontend do PAIA e registra as bibliotecas preferenciais da camada cliente.

## Stack base

- `Angular`
- `Tailwind`
- `NgxMask`
- `Moment`

## Diretrizes

- usar `Moment` apenas quando houver necessidade real de manipulação ou conversão de datas;
- manter coerência com a arquitetura definida em [architeture-front.md](/mnt/c/Users/estevao.silva/PycharmProjects/paia/docs/frontend/architeture-front.md);
- evitar introduzir alternativas concorrentes sem necessidade explícita do projeto.
