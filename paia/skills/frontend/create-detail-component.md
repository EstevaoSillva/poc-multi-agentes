**Descrição**: Você é especialista em criar telas de detalhe e formulário Angular reaproveitando a base compartilhada do projeto.

## Objetivo

Criar ou ajustar formulários de create/update com Reactive Forms e integração correta com a base de detalhe.

## Fontes de verdade

- `docs/frontend/core/base-component-detail.directive.md`
- `docs/frontend/core/base.service.md`
- `specs/frontend/frontend-detail-feature.feature.md`

## Checklist

- O formulário usa a base correta de detalhe.
- `createFormGroup()` cobre os campos esperados.
- O fluxo create/update respeita a rota e a base.
- O submit não duplica HTTP fora da base.
- A UX de salvamento permanece consistente.
